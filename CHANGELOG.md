# Changelog

## 0.4.0 - 2026-09-16

- Wired Git metadata and the release gate into the CLI.
- Added real branch, upstream, remote, and tag extraction from `.git`.
- Added exact file sizes for text and binary files.
- Added scan warnings, depth limits, and missing output-directory creation.
- Added configurable trend files.
- Added unified JSON escaping.
- Added unknown-rule and duplicate-rule configuration validation.
- Expanded the suite to 92 passing tests.

## 0.3.0 - 2026-09-16

- Added real directory scanning with deterministic ordering.
- Added cross-platform configuration, report, and baseline file I/O.
- Added command-line options for roots, profiles, output formats, output paths, ignores, and failure gates.
- Added automatic `moonbit-health.conf` discovery.
- Added JSON audit bundles that can be reused as future baselines.
- Added CI report generation and artifact upload.
- Expanded the suite to 85 passing tests.

## 0.2.0 - 2026-09-16

- Added project inventory and path classification.
- Added configurable community, release, and strict policies.
- Added report baselines, structured diffs, and readiness trends.
- Added policy decisions, severity budgets, and required evidence checks.
- Added impact-ranked remediation actions.
- Added 32 tests for the expanded audit engine.
- Reached more than 2,350 effective non-test MoonBit source lines.

## 0.1.0 - 2026-09-12

- Added deterministic project health rules.
